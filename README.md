# Нити — атлас истории IT

Карта занимает всю область окна. Панель линий скрывается; масштаб и режим «Вся история» помогают исследовать разные периоды. Содержание отделено от интерфейса и хранится в `content/`.

**[Открыть карту на GitHub Pages](https://doomer94.github.io/niti-it-atlas/)**

Сайт автоматически обновляется после изменений в `main`: workflow `.github/workflows/deploy-pages.yml` проверяет базу, собирает данные и публикует статическую папку `dist`. Node.js используется только при сборке в GitHub Actions; посетителю сайта он не нужен.

## Редактирование исторических данных

Сначала прочитайте [стандарт хранения](docs/CONTENT-SPEC.md). Для добавления или расширения события редактируйте Markdown, а не `dist/data.js`. Статус всех перенесённых записей — `draft`; наличие ссылки не равнозначно редакционной проверке.

Для редактирования базы достаточно Git и текстового редактора. Для проверки и генерации JSON нужен Node.js 22+ локально или в CI. YAML-парсер уже включён в `vendor/` с лицензией; устанавливать пакеты не нужно. Серверный процесс, база данных и Node.js на хостинге не требуются: сайт состоит из статических файлов.

```sh
node scripts/build.mjs
node --test tests/content.test.mjs
node scripts/serve.mjs
```

Первые две команды выполняют сборку и проверки. Третья запускает только необязательный локальный предпросмотр: откройте `http://127.0.0.1:4174`. После изменения данных повторите сборку и обновите страницу. Сборка создаёт `dist/data.js` и `dist/knowledge.json`. HTML/CSS/JS интерфейса находятся в `dist/` и не перезаписываются сборщиком данных.

В [CONTRIBUTING.md](CONTRIBUTING.md) описан порядок работы через Git. В `templates/` лежат шаблоны всех шести типов записей. Проверка pull request настроена в `.github/workflows/check-content.yml`; публикацию она не выполняет.

Для автономного HTML:

```sh
node scripts/export.mjs ./niti.html
```

Автономный файл содержит интерфейс и данные; внешние источники открываются через Интернет. Для обновления размещённого сайта требуется публикация нового состояния исходников. Локальная сборка сама его не публикует.
