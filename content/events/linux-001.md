# Linux 0.01: раннее ядро

## Кратко

Торвальдс распространяет исходники раннего Linux для i386.

## Задача

Как создать собственное Unix-подобное ядро для доступного персонального компьютера?

## Значение

Открытая публикация исходников позволяет другим людям изучать и развивать ядро.

## Примечание

Linux здесь — ядро. GCC и Bash уже используются вместе с ним; это не доказательство, что GNU и Linux — один проект. Версия 0.01 имела первоначальные условия распространения; переход к GNU copyleft отражён в 0.12. Точная дата выпуска в этой карточке не установлена.
