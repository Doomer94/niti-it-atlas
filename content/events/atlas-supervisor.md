# Atlas: запуск с Supervisor

## Кратко

Atlas начинает работать с ранней версией Supervisor.

## Задача

Как автоматически управлять заданиями, устройствами и памятью большой вычислительной системы?

## Значение

Системное ПО координирует ресурсы вместо ручного ведения каждого задания.

## Примечание

В декабре 1962 Supervisor ещё имел ограниченную функциональность; полное развитие заняло дополнительное время. Запуск компьютера не равен завершению всей ОС.
