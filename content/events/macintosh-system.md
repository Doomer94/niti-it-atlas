# Macintosh: системная среда с GUI

## Кратко

Apple представляет Macintosh со встроенной графической средой, меню и управлением мышью.

## Задача

Как сделать работу с программами и файлами доступной через визуальные действия?

## Значение

Персональная системная среда объединяет экранный рабочий стол, приложения и управление файлами.

## Примечание

Карточка описывает выпуск компьютера вместе с его системной средой. Это не первый GUI в истории; название Mac OS и архитектура позднейшего Mac OS X не переносятся на 1984.
