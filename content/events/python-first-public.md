# Первая публичная версия Python

## Кратко

Ван Россум публикует раннюю версию Python.

## Задача

Как получить расширяемый язык для повседневных задач с учётом опыта ABC?

## Значение

Доступная публикация открывает путь к развитию языка за пределами первоначального коллектива.

## Примечание

Начало реализации — декабрь 1989, публичная версия — февраль 1991. Здесь сохранена точность месяца без спорного номера раннего архива.
