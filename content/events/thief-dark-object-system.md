# Thief и Dark Object System

## Кратко

В Thief используется Dark Object System: свойства и отношения объектов задаются и редактируются через общую систему данных.

## Задача

Как дать дизайнерам управлять игровыми сущностями?

## Значение

Другой способ организации данных становится примером для архитектурного сравнения.

## Примечание

Муратори сопоставляет эту систему с ECS. Её исторический приоритет не установлен этим разбором. Сходство со Sketchpad не доказывает прямого влияния.

## Подробнее

Связанный фрагмент доклада Муратори: 00:00:50–00:07:18; 02:03:00–02:11:59. Таймкоды получены из автоматических субтитров и требуют сверки при точном цитировании.
