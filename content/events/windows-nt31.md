# Windows NT 3.1

## Кратко

Microsoft выпускает Windows NT 3.1 — первую версию новой линии NT.

## Задача

Как построить систему с защищённой памятью, многозадачностью и переносимой архитектурой?

## Значение

У Windows появляется отдельная системная основа для рабочих станций и серверов.

## Примечание

NT не является очередной версией ядра MS-DOS. Совпадающие номера Windows 3.1 и Windows NT 3.1 не означают одинаковую архитектуру.
