# Анонс JavaScript

## Кратко

Netscape и Sun объявляют JavaScript для браузерных сценариев.

## Задача

Как добавить в веб-страницы программируемое поведение без тяжёлой модели приложения?

## Значение

Браузер получает язык для пользовательских сценариев и обработки событий.

## Примечание

Прототип и LiveScript в бета-версии появились раньше. JavaScript — отдельный язык, не переименование Java; 4 декабря — дата совместного анонса.
