# Публичный дебют Java

## Кратко

Sun представляет Java на конференции SunWorld.

## Задача

Как предложить язык и среду выполнения для программ на разных платформах?

## Значение

Проект, выросший из Green/Oak, получает публичную платформу распространения.

## Примечание

Публичный дебют 1995 и выпуск JDK 1.0 в 1996 — разные этапы. Указана роль Гослинга; список разработчиков не является полным.
