# Публикация отчёта ALGOL 60

## Кратко

Публикуется коллективный отчёт ALGOL 60 под редакцией Петера Наура.

## Задача

Как точно описать язык записи алгоритмов для международного сообщества?

## Значение

Блоки и процедуры получают формальное описание, ставшее опорой для следующих языков.

## Примечание

Это исходный отчёт 1960, а не Revised Report 1963; Наур — редактор, не единственный создатель языка.
