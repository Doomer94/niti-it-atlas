# Деннис Ритчи · The Evolution of the Unix Time-sharing System

История участника разработки: Unix возник в 1969 на PDP-7; контекст выхода Bell Labs из Multics; переписывание ядра на C в 1973. Содержит описание преемственности идей и изменений языка реализации.
