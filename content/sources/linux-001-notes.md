# Линус Торвальдс · Notes for Linux Release 0.01

Исходные заметки к версии 0.01, 1991: ядро для i386, компиляция GCC, использование Bash. Архивная версия, а не современное описание Linux. GPL не приписывается версии 0.01: смена условий отражена в заметках 0.12.
