# Проект GNU

Проект свободной Unix-совместимой системы, объявленный в 1983. Это проект, не зарегистрированная компания.

Основание: [Ричард Столлман · Initial GNU Announcement · 27 сентября 1983](https://www.gnu.org/gnu/initial-announcement.html).
